## 7. 한계와 남은 일

- 업무 자료는 아직 팀 공유 DB 가 아니라 각자의 브라우저(localStorage)에 저장합니다. 구매 · 생산관리가 같은 데이터를 함께 보지 못합니다.
- 실제 수불 엑셀 · 생산계획 · MOQ · 리드타임 표를 아직 받지 않아, 샘플은 제출 글의 항목대로 만든 가상 값입니다.
- 안전재고 · 리드타임 · 장기 · 불용 기준은 임시 기본값입니다.
- lot 절단 계획 · 대체 규격은 직접 반영하지 않습니다(출고 변동으로 알림만).
- 발주서 양식 출력 · ERP 연동은 하지 않습니다(엑셀 내보내기).
- 로그인 뒤 화면(게시판 · 관리 · 첫 화면 고르기)은 가짜 Supabase 로 화면 흐름을, 로컬 PostgreSQL 과 과정용 프로젝트에서 SQL 권한을 확인했습니다. 실제 계정으로 로그인해 누르는 확인은 요청자 몫입니다.
- 독립 운영까지 남은 것: 본인 Supabase 프로젝트에 auth.sql · board.sql · site.sql 실행 → js/auth-config.js 의 url · anonKey 교체 → 다시 배포(supabase/README.md)
